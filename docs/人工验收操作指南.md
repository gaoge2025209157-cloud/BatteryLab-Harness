# ElectrochemHarness 知识点与数据流程核对指南

## 1. 核对目的

这个窗口不检查规章、角色签字、发布门、Git、安装或CI，只帮助研究者核对一次完整研究闭环中的两类实际结果：

1. 大模型从论文原文中读到的知识点是否真实、准确、可定位，并适用于当前实验；
2. 实验数据从导入、循环划分、指标计算到结论和下一轮建议的流程是否正确。

主界面点击“知识点与数据流程核对”。状态保存在 `outputs/manual_acceptance/acceptance_state.json`，记录导出到 `outputs/manual_acceptance/知识点与数据流程验收报告.md`。

## 2. 建议准备的材料

- 本轮实验原始数据和设备软件循环汇总；
- 电池体系、温度、电流、载量、压力、截止条件等实验记录；
- 本轮检索到的论文原文；
- Harness生成的文献清单、文献学习结果、关键结论和研究结论与指导；
- 若要复核积分，准备一个完整循环的人工计算表。

不要在备注中保存密码、Token或数据库Cookie。

## 3. 文献原文知识点核对

### KN-01 逐篇核心结论

逐篇打开原文，核对模型提炼的研究问题、方法、核心发现、正文位置和限制。题名、摘要或元数据只能帮助筛选，不能替代正文证据。

### KN-02 领域背景与专业基础

判断背景知识和电化学概念是否确实来自原文，是否写清适用条件和失效边界。删除重复、空泛或与当前课题无关的内容。

### KN-03 图表参数与实验逻辑

对照Figure、Table、图注和方法，核对数值、单位、温度、压力、载量、倍率、循环数及质量口径。读图估计必须明确标记，不能冒充作者正文报告值。

### KN-04 与本实验相关的候选知识

在最终结果页逐条选择候选知识。只有核对了DOI、正文位置和适用条件的条目才批准；证据不足、条件不匹配或表述过强的条目拒绝或暂缓。

### KN-05 本轮新增认识与冲突

检查本轮是否真正补充了新认识，是否说明与既有知识一致、补充或冲突，以及下一轮还要回答什么。知识库不应重复堆积题录或摘要。

## 4. 实验数据流程核对

### DF-01 数据识别与循环划分

抽查首圈、中间循环和末圈，核对输入列、单位、时间顺序、电流方向、容量段、循环边界和中断循环。未完成循环不得用于不成立的效率与保持率。

### DF-02 关键指标计算结果

至少独立复算一个完整循环，核对：

- 充放电容量或比容量；
- 库仑效率与容量保持率；
- 容量加权平均充放电电压；
- 平均充放电电压差；
- 主充放电平台；
- 绝对能量，或按文件质量口径估算的比能量；
- 能量效率。

按比容量和平均电压得到的结果只能称为文件质量口径下的比能量。没有整电池质量或体积时，不得称为整电池质量能量密度或体积能量密度。

### DF-03 循环趋势与异常

回到原始曲线核对容量变化率、效率波动、平均电压与平台漂移、极化变化和异常循环。单点波动不能写成长期趋势，数据异常不能直接解释成材料机理。

### DF-04 数据结论与文献依据

每条结论先核对本次数据依据，再核对已批准原文知识。结论应明确：

- 数据直接支持什么；
- 不能支持什么；
- 哪些只是候选解释；
- 支持证据和缺失证据是什么；
- 哪些替代解释仍然存在。

### DF-05 下一轮实验与课题建议

每项建议应具体到待回答问题、单一主要变量、对照组、测试或取样时点、预期支持结果和反证结果。建议必须能区分候选解释，不能只罗列“做EIS、做XPS”。

## 5. 推荐操作顺序

1. 完成一次完整研究闭环；
2. 先核对KN-01至KN-03中的原文内容；
3. 在结果页逐条批准、拒绝或暂缓候选知识；
4. 核对KN-05中的知识增量和冲突；
5. 按DF-01至DF-03检查数据流程与指标；
6. 按DF-04检查最终判断是否同时受到数据和原文支持；
7. 按DF-05确认下一轮实验可以实际执行并具有判别力；
8. 在窗口中记录DOI、正文位置、数据编号、运行目录和发现的问题。

核对结果只表示本轮知识点和数据流程的人工确认状态，不自动替代后续实验，也不把候选机理升级为事实。
