## 一、先建立私有审核目录

请把真实数据放在项目的 `private_data/j_review/` 下。该目录已被Git忽略，不会进入发布包。不要把样品真实名称、未公开配方、姓名或设备账号写入可提交文件。

建议结构：

```text
private_data/j_review/
├─ raw/                   # 原始蓝电导出，只读保留
├─ reference/             # 蓝电软件导出结果或人工抄录表
├─ screenshots/           # 软件界面口径截图，可选
└─ J_review_results.csv   # 使用模板填写
```

## 三、准备最小真实样例集

每个文件使用脱敏编号，不使用材料真实代号。优先提供：

1. `J-01-normal`：正常完整循环，至少3圈；
2. `J-02-unit`：A、mA或μA单位中至少两种；
3. `J-03-sign`：确认正负电流方向；
4. `J-04-cv`：包含恒压阶段；
5. `J-05-incomplete`：末圈未完成；
6. `J-06-time`：时间重复、舍入或倒退；
7. `J-07-negative-voltage`：存在负电压点；
8. `J-08-capacity-reset`：三列比容量每段归零；
9. `J-09-format`：至少两种常见蓝电导出表头/分隔符；
10. `J-R01`至`J-R03`：同批次、同条件的3个独立平行电池。

如果某类真实数据暂时没有，在状态中写“缺失”，不要人为制造真实样例；程序已有合成边界测试。

## 四、从蓝电软件抄录参考结果

对每个完整循环，至少记录：

- 充电容量与放电容量；
- 充电/放电比容量及质量分母；
- 库仑效率；
- 软件显示的循环完整性；
- 若软件提供，再记录平均充放电电压和能量。

所有百分数注明是百分数（例如98.5%）还是小数（0.985）。每个参考结果必须关联输入文件SHA-256、软件版本和截图/导出来源。

## 五、运行Harness并对照

标准答案技术自检：

```powershell
py -3 '.\run_phase2_validation.py' --output '.\private_data\j_review\phase2_validation.json'
```

每个真实文件再通过GUI或现有命令生成结果。把Harness结果与蓝电软件逐圈对照，记录：

```text
绝对差 = Harness - 蓝电软件
相对差 = |Harness - 蓝电软件| / |蓝电软件|
```

J只记录差异和可解释原因，不自行决定最终允许误差。C将依据数据精度、积分方式和独立复算确定误差门槛。
