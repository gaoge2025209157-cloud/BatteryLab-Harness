# 电化学核心指标科学标准 v1.0.0

> 机器身份由 `scientific_standard.py` 生成；当前状态为 `frozen_pending_domain_review`。修改任何口径必须升级版本并重新生成标准答案，禁止在原版本内静默改变公式。

## 1. 适用范围

本标准仅适用于恒流/恒压循环的文本导出数据：①循环号—时间—电流—电压；②测试时间—比容量—电压。CV、EIS、GITT/PITT不适用。

## 2. 冻结口径

1. 默认正电流为充电；只有用户明确配置并写入审计时才可反转。
2. 电流积分采用分段线性梯形法；区间内电流跨零时在零点拆分，充放电容量不得互相抵消。
3. 恒压阶段只要包含实测电流与时间，就计入容量和能量；静置零电流不贡献容量。
4. 比容量分母是活性物质质量（g）。缺失质量时只报告绝对容量，不猜测比容量。
5. 库仑效率：`Q_discharge / Q_charge`；容量保持率：当前完整圈放电容量/首个完整圈放电容量。
6. 不完整循环保留用于质量检查，但不用于效率、保持率、平行电池趋势和重复性结论。
7. 平均电压按容量增量加权；在电流积分模式下等价于对应能量/容量。
8. 主平台使用固定0.05 V电压箱；取承载正容量增量最多的箱，并报告该箱内容量加权电压。该值不等于机理归属。
9. 电流积分要求时间严格递增；三列导出时间发生舍入重复时禁止重新积分，使用仪器导出的比容量并报警。
10. NaN/无穷值无效；统计异常仅提示，不自动排除。

## 3. 平行电池统计

- 同一实验组必须共享完整实验条件指纹；不同体系、倍率、温度、归一化口径或批次不得混为一个组。
- 至少3个独立电池才标记为“重复性统计”；1–2个只能标记为“探索性”。
- 对每个真实循环号分别计算算术均值、样本标准差（n−1）、标准误及双侧95% Student t区间。
- 报告必须保留每个电池的原始散点。
- MAD异常提示仍纳入统计；人工排除必须给出事前规则和理由，并在CSV/JSON中保留原值。

## 4. 标准答案数值检查

`ground_truth_v1.json`中的数值由可解析的极简案例独立推导，不从程序输出回填。运行：

```powershell
py -3 '.\run_phase2_validation.py' --output '.\phase2_validation.json'
```

输出中的`reference_checks_passed`只回答一个问题：当前解析、积分和指标计算是否与冻结参考值及允许误差一致。它不依赖指定角色或签字，也不替代对论文知识点和本轮实验解释的人工核对。

当数据格式、公式、标准版本或允许误差发生变化时，必须保留旧版本并新建参考套件，不能用当前程序输出反向覆盖参考值。

## 5. 待团队补充的真实基准

当前极简套件覆盖跨零点解析积分和三列容量/平台计算。稳定发布前仍须补充：A/mA/μA单位变化、反向电流约定、恒压段、时间倒退、不完整循环、负电压、容量重置异常、至少两种真实蓝电导出，以及与蓝电软件和人工计算的三方对照。
