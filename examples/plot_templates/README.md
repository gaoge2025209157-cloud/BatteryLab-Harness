# 电化学图谱CSV模板

这些文件只含合成示例，不是实验结果。使用时复制对应文件，保留第一行标准列名，用自己的数据替换其余行。

- `charge_discharge.csv`：充放电曲线；
- `cycling_efficiency.csv`：循环容量和库仑效率；
- `rate_capability.csv`：倍率性能；
- `dqdv.csv`：微分容量；
- `cv_lsv.csv`：CV或LSV；
- `eis_nyquist.csv`：EIS Nyquist；
- `eis_bode.csv`：EIS Bode；
- `gitt_pitt.csv`：GITT或PITT；
- `arrhenius.csv`：电导率–Arrhenius；
- `dc_polarization.csv`：直流极化；
- `ccd.csv`：临界电流密度。

完整单位换算、科学问题和解释边界见项目内 `docs/电化学图谱与数据格式规范.md`。
